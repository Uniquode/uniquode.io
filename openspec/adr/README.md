## Status Values

- `Living`: Maintained as a current reference document rather than a point-in-time decision record.
- `Proposed`: Under discussion.
- `Provisional`: Approved for current use, but intentionally subject to revision.
- `Accepted`: The project should follow this decision.
- `Superseded`: Replaced by a later ADR.
- `Deprecated`: No longer recommended, but not replaced.
