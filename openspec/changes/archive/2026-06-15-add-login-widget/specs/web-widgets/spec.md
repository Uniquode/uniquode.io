## Archived Delta Summary

The `add-login-widget` change added the `login` widget feature to the web widgets capability.

The accepted requirement text is maintained in `openspec/specs/web-widgets/spec.md` as the source of truth. This archived file records that the change introduced:

- anonymous login action rendering when auth is available;
- authenticated avatar/logout rendering;
- auth-owned profile image descriptor support;
- explicit login-widget disablement;
- safe no-op behaviour when auth is absent;
- deterministic header ordering before the theme selector;
- compact responsive behaviour for login/logout controls.
