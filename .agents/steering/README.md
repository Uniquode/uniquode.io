# Steering

This directory holds project-local guidance that agents can load on demand.

Use `AGENTS.md` for the short always-loaded rules. Use these steering files for details when they are relevant to the current task:

- `uv.md`: `uv` project initialization, dependency changes, `uv run`, and package inspection rules.
- `validation.md`: baseline check commands and timeout conventions.
- `openspec.md`: project-specific OpenSpec workflow guidance.
- `architecture.md`: application layout and platform boundaries.
